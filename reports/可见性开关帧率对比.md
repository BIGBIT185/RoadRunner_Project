# 可见性开关实包帧率对比（2026-10-23）

使用同一GOOSE bag `6_Gravel_Soil_Forest_Path.bag`前35秒，1倍速；每组重新启动建图及语义节点，从收到第一帧点云起预热5秒，再按墙钟统计25秒。保持40m×40m输出、0.2m/格、80m内部滚动图、语义开启且上限2Hz、RViz开启。除可见性清理与高度上界两个布尔值外，算法配置相同。

| 项目 | 两项开启 | 两项关闭 |
|---|---:|---:|
| 点云实际到达频率 | 9.57Hz | 9.57Hz |
| 地图实际发布频率（按相邻消息墙钟时间） | 2.354Hz | 6.674Hz |
| 25秒窗口收到地图数 | 59 | 166 |
| 语义实际输出频率 | 2.000Hz | 1.999Hz |
| 几何发布主链单帧平均耗时 | 424.9ms | 149.8ms |
| 单帧耗时P95 | 479.3ms | 271.7ms |
| 可见性更新阶段平均耗时 | 274.0ms | 0.0ms |
| 建图/语义融合失败计数 | 0 / 0 | 0 / 0 |

本次地图平均发布频率提高约2.84倍。测量的是ROS地图发布频率，不是RViz渲染帧率；单帧耗时为几何发布主链，独立语义推理不累加进同一串行耗时。诊断按processed计数去重后统计，排除空闲心跳对同一帧的重复报告。

该结果仅代表同一短片段、当前硬件和参数；不是完整bag各场景稳定6.67Hz或10Hz实时保证。关闭两项会减少旧高程清理与负台阶上界证据，算法行为取舍见README。

证据：`rate-visibility_on.json`、`rate-visibility_off.json`、`visibility-rate-comparison.json`，启动日志在`logs/rate-visibility_*.log`。测量使用单个临时缓存配置，结束已删除，唯一持久`mapping.yaml`始终未改，默认两项仍true；`test`恢复标准启动命令，`rosbag`停止。
